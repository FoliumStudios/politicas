# Políticas — Folium Studios

Páginas públicas de política de privacidade dos apps da Folium Studios,
servidas pelo GitHub Pages. As lojas exigem uma URL pública e estável, e é
por isso que este repositório é separado do código dos apps.

- `canhoto/` — Canhoto (e `canhoto/suporte/`, a página de suporte)
- `coffee/` — Coffee
- `hyrox/` — Hyrox Timer

A fonte de cada página vive no repositório do app correspondente
(`PRIVACIDADE.md`, e `SUPORTE.md` quando houver); aqui fica a versão
publicada. Ao alterar uma, altere as duas.
